# interview-prep ｜ 面试准备 Skill

一个用于 [Claude](https://claude.ai) 的 Skill：针对某个**具体岗位**，自动产出一整套面试准备材料——定制化的自我介绍，加上最可能被问到的面试问题及准备要点。

只要把目标公司的岗位 JD、公司信息和你的简历给它，它就会输出可以直接拿去准备的内容。

## 它能做什么

输入：岗位 JD ＋ 公司/岗位信息 ＋ 个人简历（＋ 其他补充信息）

输出（固定五个板块）：

1. **匹配速览** —— 提炼 JD 核心诉求、你的最大优势、需要防守的风险点。
2. **定制自我介绍** —— 一段按"四段式模板"组织、可直接朗读的自我介绍。
3. **10 个最可能的面试问题** —— 按出现概率排序，每个附「考察点」和「针对你简历的回答要点」，并专门覆盖简历薄弱点的追问。
4. **反问面试官的问题** —— 3–4 个贴合公司与岗位、能体现判断力的好问题。
5. **补充建议** —— 信息缺口提示与面试前的重点准备项。

需要时，它会先联网查一下目标公司的近况，让产出更贴合这家公司而非套模板。

## 自我介绍的四段式模板

- **第 1 段 开场定位**：姓名 ＋ 学校/学历 ＋ 求职岗位 ＋ 1–2 个核心能力标签。
- **第 2 段 核心经历（STAR）**：用情境—任务—行动—结果讲最相关的一段经历，结果带可量化数据。
- **第 3 段 自驱力/差异化亮点**：体现学习力或独特能力的事例。
- **第 4 段 公司专属钩子**：为什么是这家公司/这个岗位——每投一家公司就只重写这一段，前三段可复用。

> 仓库里 `SKILL.md` 中的范例使用占位符（如【姓名】【公司】【目标公司】），请替换成你自己的信息后使用。

## 怎么使用

**方式一：安装 `.skill` 文件（推荐）**
下载本仓库的 `interview-prep.skill`，在 Claude 的设置中找到 Skills / Capabilities，上传安装即可。

**方式二：手动复制**
打开 `interview-prep/SKILL.md`，把内容作为自定义指令或 Skill 内容粘贴进 Claude。

安装后，向 Claude 发送类似下面的请求即可触发：

- "帮我准备 XX 公司这个岗位的面试，JD 和我的简历在这里……"
- "帮我改一下投这个岗位的自我介绍"
- "这个职位面试可能会问什么？"

## 说明

本 Skill 的所有示例均为占位符，不含任何真实个人信息。使用时请填入你自己的简历与目标岗位信息。
